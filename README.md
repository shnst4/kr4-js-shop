# «Напиточная» — интернет-магазин напитков

## Описание проекта

«Напиточная» - учебный многостраничный интернет-магазин напитков, разработанный с использованием HTML, CSS и JavaScript без сторонних frontend-фреймворков.
Пользователь может просматривать товары, искать и сортировать напитки, открывать подробную информацию, добавлять товары в корзину и оформлять учебный заказ.

## Используемые технологии

- HTML5: структура и семантическая разметка страниц.
- CSS3: оформление, Flexbox, Grid и адаптивная вёрстка.
- JavaScript: логика каталога, работа с DOM, событиями и формами.
- localStorage: сохранение корзины в браузере.

## Страницы магазина

- `index.html`: главная страница с популярными напитками.
- `catalog.html`: каталог с поиском, фильтрацией и сортировкой.
- `product.html`: подробная информация о выбранном напитке.
- `cart.html`: корзина с количеством товаров и итоговой стоимостью.
- `order.html`: форма оформления заказа.
- `contacts.html`: контактная информация магазина.
